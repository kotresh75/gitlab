# gitlab basic commends
1. ``` git --version ```
2. ```git config --global user.email "kotresh@mail.com"```
3. ```git config --global user.name "kotresh"```
4. ```git config --global --unset -all user.name ```
5. ```git init```
6. ```git status```
7. ```git add .```
8. ```git commit -m ""```
9. ```git log```
10. ```git diff```
