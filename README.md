# gitlab basic commends
1. To verfiy git installtion
```
git --version
```
2. To configure the mail mail
```
git config --global user.email "kotresh@mail.com"
```
3. To configure the username
```
git config --global user.name "kotresh"
```
4. To remove existing user name/mail
```
git config --global --unset -all user.name 
```
5. To Initialized new repo
```
git init
```
6. To see Files which are there in the Staging Area
```
git status
```
7. To add Files to Staging Area
```
git add .
```
8. To Save changes which are there in the Staging area with with commit message
```
git commit -m ""
```
9. To check commit history
 ```
git log
```
10. To See changes by line/ in detail
```
git diff
```
